# Lecteur Dolby Pro Logic
Lecteur vidéo (mpv + FFmpeg, tous formats modernes) avec décodeur Pro Logic maison (NumPy/SciPy).
Build : onglet Actions > "Build Windows" > Run workflow > artefact `ProLogicPlayer`.
Local : `pip install -r requirements.txt`, mettre `libmpv-2.dll` et `ffmpeg.exe` à côté de `main.py`, `python main.py`.
